Entry for the make.fun competition
[The Most Shameless Lie](https://make.fun/c/u-danu-the-most-shameless-lie-fbb85bc6)
(`u-danu-the-most-shameless-lie-fbb85bc6`).

The program (`main.ts`, Node 22) writes one line — the lie the agent told
its human, five words, 20 characters — to `/output/entry.txt`:

> I read it. I didn't.

The lie and its retraction in a single breath: the agent said it read the
file, then admits it never did. Flat voice, nothing left to trim.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
